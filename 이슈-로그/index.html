ISSUE 01

GitHub Pages가 Private 저장소에서 동작하지 않음

증상

저장소를 Private 상태로 두고 GitHub Pages를 켜려 하면, 무료 개인 플랜은 Private 저장소에 대해 Pages를 지원하지 않아 활성화가 거부됩니다. (Pro/Team/Enterprise 플랜에서만 Private 저장소 Pages 지원)

해결

공개해도 문제없는 내용인지 커밋 이력 전체를 git log --all --diff-filter=A --name-only로 훑어 민감 파일 유무를 먼저 확인한 뒤, 저장소를 Public으로 전환하고 gh api repos/:owner/:repo/pages로 Pages를 활성화했습니다. 이후 https://frontierall.github.io/class-html-2608/로 정상 공개를 확인했습니다.

ISSUE 02

교안 HTML에 문서 구조가 없어 한글이 깨짐

증상

일부 교안 파일이 <!DOCTYPE html>·<head>·<meta charset="UTF-8"> 없이 본문 태그(<h1> 등)로 바로 시작하는 조각 형태였습니다. 브라우저가 인코딩을 잘못 추측해 한글 전체가 깨진 문자로 표시됐습니다.

해결

완전한 HTML5 문서 구조(doctype, head, meta charset)를 갖추고 사이트 공통 디자인 톤으로 다시 작성했습니다. 이후 새로 추가하는 교안 파일은 항상 이 구조를 기본 템플릿으로 사용합니다.

ISSUE 03

교안 폴더에 민감한 원본 스크린샷이 함께 있을 위험

증상

Supabase Personal Access Token, Google OAuth 클라이언트 보안 비밀번호가 찍힌 화면 캡처가 교안 자료 폴더 주변에 함께 존재했습니다. 그대로 커밋하면 저장소가 Public으로 전환됐을 때 자격 증명이 노출될 수 있었습니다.

해결

실제 교안에 삽입된 이미지는 토큰·비밀번호 값이 이미 블러 처리되어 있는 것을 하나씩 열어 직접 확인했습니다. 원본 미편집 스크린샷 폴더(Personal Access Token/, google로그인기능/)는 .gitignore에 추가해 애초에 커밋 대상에서 제외했습니다.
